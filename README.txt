# LOVE_LETTER_RETRO_PIXEL

موقع حب تفاعلي Retro / Pixel Art مبني ليحاكي تجربة الفيديو المرجعي:

1. شاشة الظرف.
2. فتح الرسالة.
3. نافذة LOVE_LETTER.EXE.
4. سؤال وزر YES.
5. انتقال احتفالي مع قلوب وConfetti.
6. موسيقى مأخوذة من الفيديو المرفوع، وتبدأ بعد تفاعل المستخدم بسبب قيود تشغيل الصوت في المتصفحات.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

لأفضل تجربة، يمكن تشغيله عبر أي Local Server بسيط.

## التعديل
- النصوص: `index.html`
- الألوان والحركات: `styles.css`
- التفاعلات والموسيقى: `script.js`
- الصور والموسيقى: مجلد `assets`

ملاحظة: ملف `assets/love_music_2min.mp3` هو المسار الصوتي الأساسي، ومدته دقيقتان ويُعاد تلقائيًا عند انتهائه.
